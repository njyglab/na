# 0001 — 연구와 패키지가 공존하는 모노레포

날짜: 2026-09-22

상태: 채택. 사용자가 연구 공간과 하위 패키지를 포함한 모노레포 구성을 요청했다.

## 맥락과 결정

기술 스택은 추가 연구가 필요하다. 하나의 Git 저장소에 `docs/`, `research/`, `packages/`, `experiments/`를 두어 연구와 코드 변경을 함께 추적한다. 언어별 workspace 설정과 빌드 도구는 아직 도입하지 않는다.

## 대안과 결과

연구와 코드를 별도 저장소로 나누는 대신 함께 버전관리한다. 루트에 단일 앱을 고정하는 대신 하위 패키지에 구현한다. 현 단계의 모노레포는 폴더와 운영 규칙이며 통합 빌드 시스템은 아니다.

패키지 경계·버전·배포 정책은 실제 구현 단위가 생길 때 구체화한다. 개인 데이터는 개발 저장소와 분리한다.
