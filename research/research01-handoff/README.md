# Personal Knowledge Systems 연구 인수인계 패키지

작성일: 2026-09-23 · 상태: 연구 방향 정리 완료 / 개별 사례의 원자료 조사 전

이 문서들은 「지형도 만들기 정리」 대화와 현재 사용자의 요청을 이전 가능한 연구 문서로 정리한 것이다. 제품 명세나 조사 완료 보고서가 아니다. 프로젝트에 옮길 때 이 폴더를 `research/`로 복사하면 된다. 파일 사이의 링크는 상대 경로이므로 함께 옮길 수 있다.

## 읽는 순서

1. [next-session.md](next-session.md): 다음 세션의 목표, 첫 작업, 결정 유보 사항.
2. [pkm-study.md](pkm-study.md): 연구 목적·범위와 통합 분석 프레임.
3. [case-template.md](case-template.md): 사례 기술, 근거 기록, 4-layer 분석 양식.
4. [research-plan.md](research-plan.md): 조사 순서, 공통 시나리오, 산출물과 완료 기준.

## 핵심 합의

`사례 자체의 기술 → Knowledge → Knowledge System → Interaction → Human Outcome → na implications`

‘지형도’는 **case description schema**, 네 층은 **analysis lens**다. 사례의 고유한 문제의식·단위·행동을 먼저 기록하고 공통 vocabulary를 귀납적으로 도출한다. na의 Block/Bullet/Memo/Daily Log/Entity/Project 등을 사례에 먼저 투영하지 않는다.

## 문서의 근거와 한계

- 원대화: 「지형도 만들기 정리」, 대화 ID `6ab30d15-ae24-83ee-ad65-a7ab7d69fd8b`. 현재 세션에서 접근 가능한 전체 반환분을 확인했다.
- 현재 요청의 13개 요구사항을 연구 범위와 인수인계 기준으로 삼았다.
- 원대화에 남아 있는 검색 인용 토큰은 원문 URL로 복원되지 않았다. 따라서 과거 응답의 역사·제품 설명을 외부 검증된 사실로 승격하지 않았다.
- 이번 작업은 대화 정리와 연구 설계다. 웹 조사, 제품 실행, 역사 자료 대조, 사용자 실험은 수행하지 않았다.
- 템플릿의 상태값·시나리오·완료 기준은 연구를 실행 가능하게 만들기 위한 이번 문서의 운영 제안이다. 이전 대화에서 확정된 제품 요구사항이 아니다.
- na의 전체 정의와 기존 저장소·MVP 명세는 제공되지 않았다. 이 문서에서 na는 향후 시사점을 적용할 대상 프로젝트 이름으로만 사용한다.
