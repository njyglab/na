# 작업 어휘 — 사례에서 얻은 구별

2026-09-26. 잠정 어휘이며 통합 ontology나 제품 스키마가 아니다.

| 어휘 | 작업 정의 | 사례와 동등하지 않은 부분 |
|---|---|---|
| unit | 읽고 쓰고 가리키는 단위 | [Memos C02](../cases/memos.md)의 자원과 [BuJo C01](../cases/bullet-journal.md)의 항목은 동일 객체가 아님 |
| organization | 다시 사용하기 위한 배치·단서 관리 | Memos C04의 도구와 BuJo C02의 규칙 구별 |
| review | 기록의 의미·현재 필요를 재판단 | BuJo C03; 단순 열람과 동일하지 않음 |
| migration | 방법론이 설명하는 재판단과 이관 | BuJo C03; DB 마이그레이션·단순 자동 복사와 구별 |
| identity / time | 대상을 지시하는 이름 / 시간 단서 | Memos C02에서 구분됨; 종이 사례는 위치·날짜 규칙을 따로 확인 |

capture, retrieval, reuse는 비교를 위한 후보 어휘다. 더 많은 사례에서 원래 용어와 실제 동작을 확인하며 정의를 고친다.

## Darwin 표본에서 추가한 구별

[표본·반복 패턴·실제 작성 예시](darwin-note-patterns.md)를 먼저 읽는다. 아래는 RN·B·M의 작은 목적 표본에서 얻은 후보이며, 다윈의 정식 분류나 필수 데이터 객체가 아니다.

| 어휘 | 작업 정의 | 근거·구별 |
|---|---|---|
| material / 재료 | 기록에서 다루는 관찰·독서 내용·전언 | P01. 전언과 직접 관찰, 현재의 사실을 구별 |
| entry / 기록 항목 | 문맥·구분선 등으로 가늠하는 작성 묶음 | darwin/C03. 페이지와 일치하지 않고 경계도 불확실할 수 있음 |
| reasoning span / 추론 범위 | 여러 문장·도식·페이지에 걸친 사고의 연결 | B36–44, M9–11. 하나의 명제나 고정 크기 단위가 아님 |
| comparison / 비교 | 두 사례의 닮음·차이·관계를 나란히 시험함 | P02. 유추와 인과 증명을 구별 |
| open question / 열린 질문 | 아직 답이 정해지지 않은 확인·설명의 방향 | P03. 할 일이나 실험 실행과 동일하지 않음 |
| provisional inference / 잠정 추론 | 재료에서 가정·귀결·설명으로 나아감 | P04–05. 결론의 타당성은 별도 평가 |
| use instruction / 사용 지시 | 기록을 후속 검토·집필 등에 연결하는 자기 지시 | P06. 정보 내용과 작업 방향이 한 항목에 공존 가능 |
| re-entry cue / 재진입 단서 | 노트명·쪽수·문헌·인물 등 다시 찾을 단서 | P07. 명시 참조와 연구자가 제안한 관계를 구별 |
| revision layer / 수정 층위 | 원기록에 더해진 교정·삽입·나중 주석 | P08. 작성 날짜·이유까지 복원된다는 뜻은 아님 |
| use state / 사용 상태 | 읽고 활용·선별·이관한 상태에 관한 흔적 | darwin/C05–06. 사용 완료와 내용의 참/거짓, 질문 해결을 구별 |
| metasystem / 기록 운영 체계 | 내용의 재탐색·검토·배치·재사용을 돕는 장치와 행동 | 보고서 §6. 다윈의 운영과 후대 편집·검색 도구를 분리 |

이 후보들은 상호 배타적 노트 종류가 아니다. 한 단락에 재료·질문·대안·참조가 함께 있어도 된다. 사람에게 분류를 먼저 요구하는 근거로 쓰지 않는다.
