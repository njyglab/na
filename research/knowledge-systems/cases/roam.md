# Roam Research — 블록 재사용에서 AI가 접근하는 그래프까지

## 대상과 조사 경계

- 사례 ID: `roam`. 소프트웨어와 초기 설계 비전을 구별한다.
- 조사: 2026-09-28, Codex. 상태: 공식 문서 조사 및 공개 help 그래프 열람.
- [전체 연구: 백서와 현재 방향](../synthesis/roam-whitepaper-and-direction.md).
- 최초 비교: [루만 노트박스와 Obsidian·Roam](../synthesis/luhmann-note-system.md).
- 원래 백서, 현재 기본 기능, 공식 별도 통합, 제3자 확장, 연구자의 해석을 구별한다.
- 로그인·설치·개인 그래프 편집·MCP 연결·내보내기 왕복 실험은 수행하지 않았다.

## Knowledge / Knowledge System

Roam의 주소와 참조는 내용의 재사용을 지원한다. 그러나 동일 블록이 여러 문맥에서 사용된다는 것과 동일한 주장·근거로 유효하다는 것은 별개다. 이름 붙은 페이지 역시 개념을 모을 수 있지만 그 이름의 뜻을 형식적으로 검증하는 온톨로지가 자동 생성되는 것은 아니다.

| 책임 | 지원 또는 표현 | 남는 판단 |
|---|---|---|
| identity | 특정 페이지·블록을 참조 | 원본·복사·수정본을 언제 분리할지 |
| context | 아웃라인, 상위 경로, Linked References | 현재 논의에 적용 가능한지 |
| source / citation | 원자료 주석, 블록 링크, 별칭 | 원문 판본·인용 범위·변형 정도 |
| provenance | AI 연결별 작성 주체와 이력에 대한 설명 | 어떤 자료·모델·과정으로 생성됐는지의 충분성 |
| retrieval | 문자열·구조·의미 기반 접근 | 검색 누락, 중복 증거, 오연결 |
| governance | 연결별 권한, 로컬·원격 경로, 사용자 관행 | 실제 권한 강제와 문서상 지침의 차이 |
| reasoning | 자연어·관계로 논의 표현 | 참조 그래프가 논리적·확률적 타당성을 보증하지 않음 |

자료에서 확인되는 `참조 → 복사와 별칭 → 수정 가능한 초안`은 파생 작업을 지원하는 경로다. 그러나 실제 사용자의 특정 원문→초안→출판→수정 이력을 이번에 추적한 것은 아니다. 백서가 지향한 완전한 협업 판단 체계와 이 경로를 동일시하지 않는다.

## Interaction / Human Outcome

직접 관찰한 것은 공개 도움말의 접힌 절을 펼치고, 본문과 이를 사용한 다른 페이지의 참조 문맥을 읽는 동작이다. 편집·권한·의미 검색은 공식 설명 확인에 머문다.

백서의 생산성·판단·창의성 기대는 측정된 성과와 구분한다. 특히 의미 검색과 AI 초안이 편리해도 인용 오류, 과거 생각의 오독, 검토 비용을 함께 살펴야 한다. 장기간의 사용 효과, 도구 간 성능 우열, 협업 의사결정 개선은 아직 말할 수 없다.
