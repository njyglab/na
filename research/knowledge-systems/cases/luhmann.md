## 3. Knowledge와 시스템 분석

카드에는 개념·논증뿐 아니라 연구 방법에 대한 성찰이 담긴다. 9/8은 후자의 실제 예다. 주소를 안정화하면 다른 기록에서 재지시할 수 있지만, 그 주소가 논증의 타당성을 검증하지는 않는다. 참조 이유는 본문과 읽는 사람의 판단에 남아 있다.

| 역량 | 관행·표현 | 유지 주체·한계 |
|---|---|---|
| identity | 카드 번호 | 루만; 현대 편집 ID·스캔 ID는 별도 |
| hierarchy / sequence | 큰 구획과 국소 삽입·분기 | 루만의 번호와 편집자의 내용 복원을 구분 |
| index / retrieval | 선택적 색인 진입점, 참조 따라가기 | 루만이 선정; 검색은 포털의 추가 지원 |
| semantics / evidence | 자연어 논의와 문헌 지시 | 관계 의미·근거 충분성을 사람이 판단 |
| revision | 이전 내용에 후속 내용을 추가 | 자동 버전 기록이나 완전한 변경 계보가 아님 |
| publication | 특정 원고의 개요와 노트 재사용 | 박스의 배열과 출판물의 논증 순서는 다름 |

### Source / Citation / Provenance

- **Source:** 종이 카드와 참고한 문헌; 이 조사에서는 디지털 편집본을 통해 접근했다.
- **Citation:** 카드가 다른 주소나 문헌을 가리키는 표기. 포털의 클릭 가능한 링크는 이를 읽기 쉽게 만든 표현이다.
- **Provenance:** 작성·추가·수정 시점과 과정. 날짜 없는 카드가 많고 서지→내용 주소가 전수 기록되지 않아 전체 추적을 보장하지 않는다.

현재 확인한 작은 경로는 `9/8 → 보충 9/8,1 → 9/8 복귀 → 9/8a`다. 외부 원문→발췌→파생 주장→출판물까지 이어지는 완전한 계보는 이번 표본에서 입증하지 않았다. 편집자의 1980/81년 추정은 확정 작성일로 바꾸지 않았다.

## 4. Interaction과 Human Outcome

온라인 인터페이스는 물리적 이웃과 논의의 이웃을 선택하도록 한다. 이 선택과 복귀는 직접 관찰했다. 원고를 읽는 부담, 국소 그래프가 이해에 기여하는 정도, 장기 재탐색 성공률은 측정하지 않았다.

루만의 생산성과 노트박스의 존재는 그 체계가 누구에게나 같은 성과를 낸다는 인과 증거가 아니다. 이 사례에서 우선 확인 가능한 것은 지식을 주소화·연결·재방문하는 방식이다. 창의성·이해·출판량의 개선은 별도 평가 질문으로 남긴다.
