## 2. 첫 조사 묶음

### A. Memos + Bullet Journal

선택 이유는 빠른 포착과 이후 의미 부여·검토 비용을 비교할 수 있을 것이라는 가설이다. 우열이나 확인된 제품 특성은 아니다.

1. Memos의 정확한 프로젝트와 버전, BuJo의 당사자 방법론 자료를 식별한다.
2. 각 사례의 Problem/Primitive/Core Operations를 자체 용어로 적는다.
3. 시간성, 조직 시점, review/migration, 검색, 인간 부담을 확인한다.
4. 생각·할 일·관찰을 포착하고 나중에 다시 판단하는 장면을 비교한다.
5. 입력 비용이 낮아진 만큼 뒤의 정리·재탐색 비용이 늘어나는지, 검토 노력이 유용한 판단을 유도하는지 질문한다.

최소 산출물: `cases/memos.md`, `cases/bullet-journal.md`, 첫 비교 메모와 근거 목록. 설치나 데이터 이관은 이 연구의 선행 조건이 아니다. 직접 실행하지 못한 부분은 문서 근거로만 보고한다.

### B. Darwin + Luhmann

개인 기록이 관찰·사고·재결합에 연결되는 방식을 원자료에서 비교한다. 역사적 인물의 성과를 기록법 하나로 설명하지 않는다.

1. 신뢰할 수 있는 아카이브와 연구 자료를 찾고 자료군·시기를 제한한다.
2. 실제 기록의 단위, 배치·참조, 날짜·맥락·인용 흔적을 확인한다.
3. 기록에서 해석·후속 기록·산출물로 이어지는 연결을 추적한다. 추적되지 않으면 그 한계를 남긴다.
4. 당시 실천, 당사자의 설명, 후대 해석, 현대 디지털 아카이브 기능을 분리한다.
5. 루만에게 현대의 atomic/permanent/structure note 규범을 그대로 소급하지 않는다.

최소 산출물: `cases/darwin.md`, `cases/luhmann.md`, 해석을 뒷받침하는 원자료 위치와 자료 접근 한계.

### C. 이후 Notion / Obsidian / zhfahim/anchor

앞 묶음에서 얻은 vocabulary로 비교하되 새로운 primitive와 행동을 수용하도록 어휘를 수정한다. 기본 기능, 플러그인, 사용자 관행, 외부 도구를 구분한다. Anchor는 저장소 정체·목적 확인부터 시작한다.

Commonplace book, GTD, Leonardo, Memex, Engelbart는 지형도에 포함하고 조사 깊이는 설명력과 자료 접근성에 따라 정한다. Xanadu는 epistemic lineage 비교에 필요할 때 확장한다. 관련 학술 연구는 각 사례의 해석·성과 주장에 필요한 시점에 연결한다.

## 3. 공통 사용자 시나리오

아래는 이번 정리에서 제안하는 비교용 장면이며, 사용자 실험 결과가 아니다.

| ID | 동일하게 주는 상황 | 목표 | 비교할 관찰 |
|---|---|---|---|
| S1 포착 | 이동 중 생각·할 일·관찰이 연속 발생 | 누락 없이 남기고 활동 재개 | 입력 시간, 필수 선택, 잃은 맥락 |
| S2 근거와 수정 | 자료를 읽고 기존 생각 A를 B로 수정 | 원문·해석·수정 이유를 보존 | citation 위치, lineage, 이전 주장 처리 |
| S3 재탐색 | 몇 주 후 표현은 기억나지 않지만 당시 맥락은 기억 | 관련 기록을 찾아 사용 | 단서, 탐색 경로, 성공·실패, 소요 노력 |
| S4 재결합 | 흩어진 기록으로 설명이나 짧은 글 작성 | 새 산출물과 근거 연결 | 맥락 복원, 재조합, 인용 누락 |
| S5 검토·행동 | 미완료 기록이 축적되고 일부는 불필요해짐 | 실행·보류·폐기 판단 | review 부담, 판단의 질, 행동 재개 |
| S6 대체 | 신뢰하던 자료의 오류를 발견 | 관련 주장·결과물 수정 | 파생 추적, 경고·대체·철회 표현 |

동일한 입력 자료, 목표, 가능한 시간, 지연 기간을 유지한다. 사용자 숙련도·제품 설정·검색 가능한 데이터량은 기록한다. 역사 사례와 개념 명세에는 동일 작업을 강제하지 않고 자료에 근거한 대응 분석으로 표시한다. 시간 여행식 사용성 실험을 꾸미지 않는다.

측정은 우선 성공 여부, 필요한 결정 수, 시간, 맥락·근거 보존, 수정·검토 노력으로 제한한다. 기억·학습의 장기 효과는 별도 관찰이 필요하다. A/B 실험으로 진행할 경우 같은 기록과 목표를 유지하고 한 번에 한 상호작용을 바꾼다. 실행 전에는 가설로 표시한다.

## 4. 공통 vocabulary와 지도

첫 후보: capture, unit, identity, time, organization, reference, retrieval, review, reuse.

각 용어에 작업 정의, 사례의 원래 용어, 공통점, 동등하지 않은 부분, 근거 사례를 기록한다. 예를 들어 Memo/Bullet/Block/Zettel을 모두 note로 번역하더라도 주소·수정·배치·사용 의미를 지우지 않는다.

지도 축 후보는 시간 중심성, 조직 시점, chronological/associative retrieval, 사용자 부담의 위치다. 사례를 읽은 뒤 설명력이 있는 축만 채택한다. 단일 점수·종합 순위보다 조건별 적합성과 trade-off를 보여준다.
